# Промт для Claude Code: карточки отзывов + переход на страницу тура

## Перед запуском: откуда возьмутся отзывы

Сейчас в разделе пустая карточка, потому что в `data/reviews.ts` нет ни одного отзыва. Придумывать отзывы нельзя, поэтому нужен хотя бы один из двух источников.

**Источник 1. Отзывы вручную (подходит всегда).** Собери реальные отзывы из WhatsApp, Instagram, Google и вставь их в блок «ОТЗЫВЫ» в конце промта. Имя и текст гостя публикуй только с его согласия.

**Источник 2. Автоматически из Google (если у KAIFO есть профиль компании в Google с отзывами).** Нужны две вещи:
- **Place ID.** Открой страницу Google «Place ID Finder» (ищется по этому названию), найди KAIFO на карте и скопируй ID. Он начинается с `ChIJ…`.
- **API-ключ.** Google Cloud Console → создай проект → подключи платёжный аккаунт → APIs & Services → включи **Places API (New)** → Credentials → Create API key → в ограничениях ключа оставь только Places API (New). Отзывы будут обновляться раз в сутки, это около 30 запросов в месяц. Стоимость проверь в разделе Billing, при таком объёме она минимальна.

Оба источника можно использовать вместе. Если не заполнен ни один, раздел останется как сейчас, с приглашением оставить отзыв.

## Если подключаешь Google-отзывы

1. После того как Claude Code закончит, создай в папке проекта файл `.env.local` со строкой:
   ```
   GOOGLE_PLACES_API_KEY=твой_ключ
   ```
2. На Vercel: проект → **Settings → Environment Variables** → добавь `GOOGLE_PLACES_API_KEY` и `GOOGLE_PLACE_ID` для Production и Preview.
3. После этого сделай push или нажми **Redeploy** в Vercel, иначе новые переменные не подхватятся.
