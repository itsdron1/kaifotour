# Промт для Claude Code: отзывы на двух языках + описание «Why KAIFO?»

## Промт для вставки в Claude Code

```
Две правки по языкам. Сначала посмотри data/reviews.ts, компоненты
карточек отзывов и модалки, секцию "Why KAIFO?" и то, как устроены
словари EN/RU. Покажи короткий план, потом выполняй.

═══════════════════════════════════════════
1. ОТЗЫВЫ: EN-ВЕРСИЯ НА АНГЛИЙСКОМ, RU-ВЕРСИЯ НА РУССКОМ
═══════════════════════════════════════════
Сейчас текст отзыва показывается на языке оригинала на обеих версиях.
Нужно: на английской версии сайта карточки отзывов на английском, на
русской — на русском.

1.1 Данные (data/reviews.ts)
  Поменяй тип отзыва:
    text: { en: string; ru: string }
    originalLang: 'en' | 'ru'          // на каком языке написал гость
    location?: { en: string; ru: string }
    author: { en: string; ru: string }
  - Текст на языке оригинала оставь дословно, как сейчас.
  - Недостающий язык переведи сам. Перевод должен быть точным: тот же
    смысл и тон, ничего не добавляй, не усиливай и не «улучшай» отзыв.
    Если в тексте есть сленг или шутка, передай смысл, а не слово в
    слово.
  - Имя гостя не переводи. На EN-версии кириллическое имя пиши
    латиницей (Анна → Anna, Дмитрий → Dmitry), на RU-версии латинское
    имя оставь латиницей.
  - Страну/город переведи (Россия → Russia, Germany → Германия).
  - Оценку, дату, источник и ссылку не меняй.
  - Выпиши мне в summary все переводы, которые сделал, парами
    «оригинал → перевод», чтобы я их проверила.

1.2 Отображение
  - Карточка и модалка показывают text[locale], author[locale],
    location[locale].
  - Если text[locale] — это перевод (originalLang !== locale), на
    карточке и в модалке мелкая пометка:
      EN: "Translated from Russian"  RU: "Переведено с английского"
    В модалке рядом кнопка "Show original" / "Показать оригинал",
    которая переключает текст на оригинал и обратно. Оригинал
    выводи с атрибутом lang={originalLang}.
  - Название тура на карточке — на языке страницы (из data/tours.ts).
  - Подпись источника на языке страницы: EN "Google / Instagram /
    WhatsApp", RU так же (это названия сервисов, не переводятся).
  - Дата: Intl.DateTimeFormat по языку страницы, месяц словом
    (EN "Sep 2026", RU "сент. 2026").
  - Все надписи раздела на языке страницы: "Show all reviews (N)" /
    "Все отзывы (N)", "Read more" / "Читать полностью", кнопка
    закрытия модалки, aria-label звёзд "Rated 5 out of 5" / "Оценка 5
    из 5", пустое состояние.
  - Отзывы из Google (если подключены) не трогай: они уже приходят на
    языке страницы через languageCode, с пометкой Google о переводе.

═══════════════════════════════════════════
2. "WHY KAIFO?": ОПИСАНИЕ
═══════════════════════════════════════════
Под заголовком "Why KAIFO?" / "Почему KAIFO?" описание должно быть
ровно таким:
  RU: «KAIFO родилось от слова «кайф» — того самого ощущения, когда всё
       сложилось и тебе просто хорошо.»
  EN: "KAIFO comes from the Russian word “kaif” — that very feeling when
       everything falls into place and you simply feel good."
- Если сейчас в описании есть другой текст (например, вторая фраза про
  «пять букв»), замени его этой одной фразой в обоих языках.
- На EN-версии не должно быть кириллицы: слово kaif пиши латиницей в
  кавычках, как выше.
- Тире длинное, с неразрывным пробелом перед ним. Кавычки: в RU
  «ёлочки» (внутри «кайф» оставь «ёлочки», внешние кавычки на сайте не
  нужны — это просто абзац), в EN “лапки”.
- Стиль абзаца не меняй (Barlow, цвет #D9CDBA на тёмном фоне).
```
