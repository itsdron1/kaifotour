# Промт для Claude Code: новый первый экран KAIFO + стопка карточек на втором экране

> Референс — первый экран travel-friends.live: крупный оффер по центру, слово-акцент рукописным шрифтом, две кнопки, фото настоящих гостей на фоне, подводка со стрелкой вниз и «рваный край бумаги» при переходе к следующему блоку. Берём композицию и приёмы, а не их материалы: фото, тексты, розовый цвет, логотип и заявление «№1» — это их бренд. У KAIFO свои цвета (Deep Ocean & Brass + оранжевое солнце из логотипа) и свои тексты.

---

## Перед запуском (по желанию, но сильно влияет на конверсию)

Главное, что продаёт у референса, — **живое видео или фото настоящих гостей**, а не сток. Если есть видео с туров:

- `public/media/hero.mp4` — горизонтальное, 1920×1080, 10–20 секунд, без звука, до ~6 МБ;
- `public/media/hero-mobile.mp4` — вертикальное, 1080×1920, для телефонов (можно то же видео, обрезанное);
- `public/media/hero-poster.jpg` — кадр из видео, показывается, пока видео грузится.

Людей в кадре публикуй только с их согласия. Если видео пока нет, Claude Code оставит текущее фото, а видео подставится само, когда файлы появятся.
