# Промт для Claude Code: заменить KAIFO на логотип

> Файлы логотипа уже лежат в проекте, в папке `public/brand/`. Ничего копировать не нужно, просто вставь промт ниже в Claude Code.

## Промт для вставки в Claude Code

```
Задача: заменить текстовый логотип KAIFO на сайте на графический логотип.
Файлы уже лежат в public/brand/:

  kaifo-logo.svg        логотип для СВЕТЛОГО фона (тёмно-синие буквы)
  kaifo-logo-light.svg  логотип для ТЁМНОГО фона (светлые буквы, волны
                        чуть светлее, чтобы читались на #0F2230)
  kaifo-logo.png,
  kaifo-logo-light.png  те же логотипы в PNG 2400px с прозрачным фоном
                        (для соцсетей и мест, где SVG не подходит)
  kaifo-icon.svg        значок (солнце + волны) для вкладки браузера,
                        сам подстраивается под тёмную тему браузера
  kaifo-icon-512.png    значок 512×512, прозрачный фон
  apple-icon.png        иконка 180×180 на тёмно-синем фоне для iPhone

Пропорции логотипа: 4352 × 1228 (ширина ≈ 3.54 × высоты).

Сначала найди все места, где KAIFO выводится как логотип (шапка,
мобильное меню, футер, возможно лоадер или другие места), и покажи
список. Потом заменяй.

1. ЛОГОТИП В ШАПКЕ, МЕНЮ И ФУТЕРЕ
- Замени текстовый вордмарк на картинку. Вариант выбирай по фону под
  логотипом:
    тёмный фон (шапка поверх hero, тёмная шапка при скролле, тёмный
    футер, тёмное мобильное меню) → /brand/kaifo-logo-light.svg
    светлый фон → /brand/kaifo-logo.svg
- Используй <img> или next/image с unoptimized (для SVG оптимизация не
  нужна). Обязательно укажи width и height, чтобы при загрузке ничего не
  прыгало:
    шапка, десктоп: высота 36px, ширина 128px
    шапка, мобильный: высота 28px, ширина 99px
    футер: высота 44px, ширина 156px
- alt="KAIFO". Логотип — ссылка на главную текущего языка (посмотри,
  как устроены маршруты app/(en) и app/(ru)).
- Удали старые текстовые элементы вордмарка: надпись KAIFO, приписку
  "BALI" рядом с ней и связанные с ними стили, если они больше нигде не
  используются.
- Упоминания KAIFO в обычном тексте ("Why KAIFO?", "KAIFO guest",
  крупные буквы K-A-I-F-O в разделе "О нас", title и описания страниц)
  НЕ заменяй на картинку. Это текст, он нужен для смысла и SEO.

2. ИКОНКА ВКЛАДКИ И IPHONE
- Сейчас есть public/favicon.svg (временная иконка). Подключи вместо
  неё /brand/kaifo-icon.svg как основной favicon и /brand/apple-icon.png
  как apple-touch-icon (180×180) через metadata.icons.
- В проекте две группы маршрутов, app/(en) и app/(ru). Проверь, что
  иконки подключены в обеих (лучше через общий объект метаданных, чтобы
  не дублировать).
- Если старый public/favicon.svg больше нигде не используется, удали его.

3. ЗАФИКСИРУЙ В CLAUDE.md
В блоке «Бренд» пропиши: пути к файлам логотипа, правило «на тёмном фоне
kaifo-logo-light.svg, на светлом kaifo-logo.svg», размеры в шапке и
футере. Логотип не перерисовывать и не перекрашивать через CSS
(filter, fill), только эти файлы.

4. ПРОВЕРКА
- Шапка на 1440, 1024, 768 и 375px: логотип чёткий, не растянут, не
  наезжает на меню, выровнен по центру высоты шапки с пунктами меню.
- Шапка поверх hero и после скролла: логотип виден в обоих состояниях.
- Мобильное меню и футер: правильный вариант логотипа под фон.
- Вкладка браузера: иконка видна и в светлой, и в тёмной теме браузера.
- В EN и RU версиях логотип ведёт на главную своего языка.
- npm run build и npm run lint без ошибок.

Коммит (добавь в него и новые файлы из public/brand/):
  feat(brand): replace text wordmark with KAIFO logo, add favicons
В конце пришли summary: в каких местах заменил логотип и что удалил.
```

## После Claude Code

Новые файлы логотипа git ещё не видел, поэтому здесь обязательно `git add`:

```bash
cd "/c/Users/MSI/Desktop/claude kaifo"
git status
git add .
git commit -m "feat(brand): replace text wordmark with KAIFO logo, add favicons"
git push
```

Если Claude Code уже сделал коммит и `git status` показывает `nothing to commit`, выполни только `git push`.
