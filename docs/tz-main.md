## 4. Дизайн и стиль

Не копировать палитру travel-friends.live 1-в-1. Использовать утверждённую фирменную палитру бренда KAIFOTOUR BALI (см. ниже) — она уже проработана отдельно под премиальное позиционирование и обязательна к применению.

### 4.1. Основная палитра — «Deep Ocean & Brass» (рекомендованное и приоритетное направление)

Тёмно-синяя океаническая база вместо курортной бирюзы + латунный (тёплый золотисто-коричневый) акцент вместо стандартного WhatsApp-зелёного. Логика: акцент используется **только** на CTA-кнопках, ценах и ключевых цифрах — везде остальное нейтрально.

| Роль | HEX | Применение |
|---|---|---|
| Тёмная база (фон хедера, hero, тёмных секций) | `#0F2230` | Header, hero-фон, блок «Why choose us», подложки тёмных секций |
| Вторичный тёмный/бирюзовый | `#14545C` | Полосы категорий/табов туров, обводки вторичных кнопок, подзаголовки-кикеры |
| Акцент (латунь/золото) | `#C0913F` | **Только** CTA-кнопки («Book via WhatsApp»), цены, номера пунктов, активные вкладки |
| Светлый песочный (вторичный фон) | `#D9CDBA` | Секция контактов/футера, разделители, светлые подложки под тёмными блоками |
| Бумажный светлый фон (вместо чистого белого) | `#F4F1EB` | Основной фон страницы вместо `#FFFFFF` |
| Текст на тёмном фоне | `#EFE7DA` | Заголовки и текст на тёмных секциях |

CSS-токены для стилей (задать как переменные и не хардкодить хексы по коду):
```css
:root {
  --color-bg: #F4F1EB;        /* бумажный фон вместо белого */
  --color-surface-dark: #0F2230;
  --color-surface-teal: #14545C;
  --color-accent: #C0913F;    /* латунь — только CTA/цены/акценты */
  --color-sand: #D9CDBA;
  --color-text-on-dark: #EFE7DA;
  --color-text: #0F2230;
}
```

### 4.2. Альтернативные направления (запасные варианты палитры, если заказчик захочет сместить акцент)

**02 — Basalt & Copper (вулканический)** — под упор на эндуро/джип/Harley, делает морские туры «экспедиционными», а не пляжными:
`#16130F` (почти чёрный фон) · `#3C3630` (графит) · `#B0654A` (медь-акцент) · `#CFC3AF` (светлый песочный) · `#F2EDE3` (бумажный фон)

**03 — Jungle & Gold (тропический нуар)** — под пары/романтику/закатные круизы, стиль бутик-отелей Убуда:
`#12251C` (тёмная зелень) · `#2F6B54` (зелёный акцент-вторичный) · `#C6A96A` (приглушённое золото) · `#D5CDB8` (светлый песочный) · `#F5F2E9` (бумажный фон)

По умолчанию верстать на палитре **01 — Deep Ocean & Brass**, но вынести цвета в CSS-переменные так, чтобы переключение на 02 или 03 требовало правки только токенов, а не разметки.

### 4.3. Правила, которые дают ощущение «дороже» (обязательны к соблюдению)

1. Никогда не использовать чистый белый `#FFFFFF` — только бумажный тон (`#F4F1EB`/аналог палитры).
2. Один акцентный цвет на весь сайт. Латунь/медь/золото (в зависимости от палитры) — только на ценах, кнопках и активных состояниях; всё остальное нейтрально (тёмная база, песочный, текстовые оттенки).
3. Кнопки бронирования НЕ красить в стандартный WhatsApp-зелёный — только в акцентный цвет палитры (`#C0913F` для основного направления). Иконку WhatsApp внутри кнопки можно оставить, но фон/заливка кнопки — акцентная.
4. Единая цветокоррекция фотографий: приглушённая насыщенность, один тёплый или холодный сдвиг на все фото сайта — не смешивать разные по тону фотографии.
5. Больше воздуха между секциями (padding 64–96px по вертикали) и крупные заголовки — плотная «каталожная» вёрстка (как сейчас на kaifotour-bali.com) визуально удешевляет сайт.

### 4.4. Типографика

- Заголовки: **Barlow Condensed** (600), uppercase, увеличенный letter-spacing (0.01–0.02em на крупных заголовках, 0.1–0.2em на кикерах/лейблах)
- Основной текст: **Barlow** (400/500)
- Подключение шрифта: `@import url('https://fonts.googleapis.com/css2?family=Barlow:wght@400;500;700&family=Barlow+Condensed:wght@400;600&display=swap');`

- **Header:** фон `#0F2230`, лого светлым текстом (`#EFE7DA`), пункты меню `#B9C4CC`, кнопка WhatsApp справа заливкой `#C0913F`
